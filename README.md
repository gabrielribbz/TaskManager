# 📋 **TaskManager**

**TaskManager** é um gerenciador de tarefas moderno e intuitivo, projetado para melhorar a sua produtividade. Organize suas tarefas de maneira simples e eficiente com uma interface limpa, fácil de usar e totalmente responsiva.

![Imagem](./imgREADME.png)

## ✨ **Funcionalidades**

- **Criar Tarefas**: Adicione novas tarefas facilmente, definindo título e descrição para cada uma.
- **Editar Tarefas**: Modifique os detalhes de suas tarefas, incluindo título, descrição e status.
- **Excluir Tarefas**: Remova tarefas que não são mais necessárias.
- **Marcar como Concluída**: Marque tarefas como concluídas para um controle visual da sua produtividade.
- **Interface Responsiva**: A aplicação se adapta a qualquer tamanho de tela, proporcionando uma ótima experiência tanto em desktops quanto em dispositivos móveis.

- **React**: Biblioteca JavaScript para criar interfaces de usuário dinâmicas e interativas.
